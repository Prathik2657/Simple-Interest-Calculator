# Simple Interest Calculator

## Introduction
This project is used to calculate simple interest easily.

## Formula
Simple Interest = (P * R * T) / 100

Where:
- P = Principal Amount
- R = Rate of Interest
- T = Time

## Features
- Easy to use
- Fast calculation
- Displays simple interest
- Calculates total amount

## Technology Used
Python

## Conclusion
This project helps users calculate simple interest quickly and easily.
